# Cinematic Dark Guardian Portfolio

A high-performance, original, and cinematic portfolio built with Next.js, Framer Motion, and Tailwind CSS. This project features a custom "Dark Guardian" identity with zero copyrighted IP assets.

## Core Features

- **Guardian Identity**: Completely original procedural SVG emblems and atmospheric effects (no Batman IP).
- **Procedural Project Covers**: Dynamic, SVG-based project covers that react to mouse movement.
- **Cinematic Atmosphere**: Custom fog systems, film grain, and volumetric lighting effects.
- **Responsive Design**: Fully optimized for all screen sizes with premium aesthetics.
- **Magnetic Interactions**: Smooth, magnetic UI elements for an immersive experience.

## Tech Stack

- **Framework**: Next.js
- **Animation**: Framer Motion
- **Styling**: Tailwind CSS
- **Icons**: Lucide React + Custom Procedural SVGs

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
